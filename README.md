# CoachOS — Kit de préparation avant build

Ce dossier est un **kit documentaire et de sources**, pas une application construite.

- `COACHOS_SPEC_V1.md` : décisions Q1–Q25, exigences, architecture, migration, sécurité, critères d'acceptation et plan de build pour Codex.
- `sources/index_original.html` : copie intacte du dashboard historique de l'utilisateur.
- `sources/stack_user_v2.json` : données Stack à six étapes reçues dans la conversation, avec 24 tracés.

**Ne pas modifier les sources originales. Ne pas publier ou lancer le build avant validation explicite.**
